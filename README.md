**Enseignant : Alain Wafflard**

---

## 📌 Description
Ce dépôt contient le **matériel pédagogique** pour le cours de **Programmation Orientée Objet (POO)**.
Il inclut :
- **Syllabus** : Plan du cours, objectifs, évaluations et ressources.
- **Exercices et projets** : Travaux pratiques pour appliquer les concepts de la POO.
- **Exemples de code** : Illustrations des concepts en **Python** (et éventuellement d'autres langages comme Java, C#, etc.).

---

## 🛠️ Prérequis
Pour utiliser ce matériel, assurez-vous d'avoir :
- Un environnement de développement (ex: **VS Code**, **PyCharm**).
- **Python 3.x** installé (ou un autre langage selon les besoins du cours).
- Un terminal pour exécuter les scripts (souvent inclus dans l'éditeur)
